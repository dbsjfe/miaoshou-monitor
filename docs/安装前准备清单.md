# 妙手ERP → TK 订单通知 · 安装前准备清单

安装本身是一条命令的事，**真正花时间的是下面这几项资料**。照着勾完再装，5 分钟能跑通；
资料不齐就装，程序能启动但一条通知都发不出去（推送失败是**静默**的，不会报错提醒你）。

---

## 一、必填项（二选一以上，缺了收不到任何通知）

### 1️⃣ 妙手 ERP 开放平台密钥 —— 取订单用，**必填**

| 要准备 | 样子 |
|---|---|
| AppKey | `ak_` 开头的一串 |
| AppSecret | 64 位十六进制串 |

**怎么拿：**

1. 登录妙手 ERP 网页版 → **系统设置 / 应用中心 → 开放平台（开放接口）→ 应用管理**
2. 新建一个应用（名称随便写，如 `订单通知`）
3. 勾选**订单查询**相关权限
4. 创建后页面上会给出 **AppKey** 和 **AppSecret**

> ⚠️ **AppSecret 通常只在创建时显示一次**，关掉页面就看不到第二次。先复制到备忘录再关。
> 已经关掉也没关系 —— 在应用列表里可以**重置 AppSecret**，重置后旧值失效。

---

### 2️⃣ 通知通道 —— 消息发到哪里，**至少配一个**

#### 方案 A：邮件（**推荐主通道**，无条数限制）

| 要准备 | 说明 |
|---|---|
| 发件邮箱地址 | 例如 `你的账号@qq.com` |
| **SMTP 授权码** | ⚠️ 不是邮箱登录密码！见下方获取方法 |
| 收件邮箱地址 | 一般就填自己，可以跟发件邮箱相同 |

**QQ 邮箱拿授权码：** 网页版邮箱 → 设置 → 账号 → 「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务」
→ 开启 **SMTP 服务** → 按提示验证手机 → 得到一串 **16 位字母**，就是授权码。

**其他邮箱同理：**

| 邮箱 | 位置 | SMTP 服务器 |
|---|---|---|
| QQ / Foxmail | 设置 → 账号 → 开启 SMTP | `smtp.qq.com`，端口 `465` |
| 163 / 126 | 设置 → POP3/SMTP/IMAP | `smtp.163.com`，端口 `465` |
| Gmail | 需先开两步验证，再生成「应用专用密码」 | `smtp.gmail.com`，端口 `465` |
| Outlook | 账户 → 安全性 → 应用密码 | `smtp.office365.com`，端口 `587` |

---

#### 方案 B：Server酱（微信直接收，**免费版每天只有 5 条**）

**适合**：只有当兜底用，或者单量很少。

1. 打开 `sct.ftqq.com`
2. 微信扫码登录
3. 页面上「SendKey」那一栏 → 复制，形如 `SCT` 开头的一串

> ⚠️ 免费版**每天 5 条**，第 6 条会失败。单量一多就必须配合邮件或其他通道。

---

#### 方案 C：WxPusher（微信直接收，**免费、无条数限制**）

**适合**：想直接在个人微信里收到，又不想被条数限制。

1. 打开 `wxpusher.zjiecode.com/admin`，微信扫码登录
2. 创建应用 → 复制 **appToken**（`AT_` 开头）
3. 在该应用页点「关注应用」，用微信扫码关注
4. 微信里进入「WxPusher」公众号 → 我的 → 我的 UID → 复制 **UID**（`UID_` 开头）

需要准备：`appToken` + `UID` 两项。

---

#### 方案 D：企业微信群机器人（免费，消息在群里看）

1. 手机/电脑企业微信 → 进入一个群（可以自己建一个只有自己的群）
2. 群设置 → **群机器人** → 添加 → 复制 **Webhook 地址**
3. 地址形如 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx`
4. 只需要 `key=` **后面那一段**

---

#### 方案 E：企业微信自建应用 —— ❌ **不推荐**

需要「企业可信IP」，未认证企业还要求先配「接收消息服务器URL」（得有公网 IP 服务器）。
家用宽带 IP 会变，基本配不通（会报 `60020`）。想省事就别走这条。

---

## 二、可选项（想要"电脑关机也能收到"才需要）

### 3️⃣ GitHub 仓库 + Token

| 要准备 | 说明 |
|---|---|
| GitHub 用户名 / 仓库名 | 例如 `yourname/order-notify`（建一个仓库，public 更省事） |
| Personal Access Token | **必须选 classic 类型** |

**拿 Token：** GitHub → 右上角头像 → Settings → Developer settings →
Personal access tokens → **Tokens (classic)** → Generate new token (classic)
→ 有效期建议 **1 年** → 勾选 ✅ `repo` ＋ ✅ `workflow` 两项 → 生成后复制（`ghp_` 开头）。

> ⚠️ 细粒度 token（Fine-grained）权限入口很绕，容易卡住。**直接用 classic 勾两个框就行。**
> ⚠️ 有效期别选 7 天 —— 这个 token 要给常驻程序每轮回写状态用，一过期就会导致**重复通知**。

## 六、最容易卡的 5 个地方

| 卡点 | 真相 |
|---|---|
| 邮件一直认证失败 | 填成了**邮箱登录密码**。必须是 SMTP **授权码** |
| 妙手接口报签名错误 | AppSecret 复制少了一位，或中途重置过 AppSecret（重置后旧值立刻失效） |
| 每天只收到 5 条 | 正在用 Server酱免费版。把邮件设为第一通道 |
| 装完一条通知都没有 | 配置里的空字段没填完。跑 `python3 local/test_push.py` 看它怎么说 |
| Mac 上没声音 | 系统静音／没允许终端发通知／程序跑在 root 的 LaunchDaemon 下（没有图形会话） |
